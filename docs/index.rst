Welcome to SynCCFD's documentation!
================================

SynCCFD (Synthetic Credit Card Fraud Detection) is a Python library for generating synthetic credit card transaction data with realistic fraud scenarios.

Features
--------

* Generate synthetic credit card transaction data with realistic patterns
* Simulate different types of credit card fraud scenarios
* Geographic data integration for location-based features
